About IDent

Advanced stylometric analysis for Swedish text identification

What is IDent?

IDent is a sophisticated text analysis system designed to extract and analyze writing style patterns from Swedish text. Unlike content-based analysis, IDent focuses on how someone writes, not what they write about.

By analyzing 67+ linguistic and stylometric features, IDent creates unique fingerprints of writing styles that remain consistent across different topics and contexts. This makes it valuable for author identification, text comparison, and style analysis.

How It Works

01

Text Preprocessing

Input text is tokenized into words and sentences using Swedish-aware regex patterns, preserving linguistic structure.

02

Feature Extraction

Five parallel analysis modules extract features: Lexical (19 features), Syntactic (13 features), Character (19 features), Swedish-Specific (11 features), and Stylometric (10 features).

03

Profile Creation

Extracted features are normalized and combined into a high-dimensional style profile representing the text's unique signature.

04

Comparison & Visualization

Profiles are compared using distance metrics (cosine, euclidean, manhattan) and projected onto 2D space using PCA or t-SNE for visualization.

Feature Categories

Lexical Features

  • Vocabulary richness (Type-Token Ratio, MTLD)
  • Word length distributions
  • Hapax legomena ratios
  • Lexical density and diversity

Syntactic Features

  • Sentence length patterns
  • Punctuation usage (19 types)
  • Sentence complexity metrics
  • Structural patterns

Character-Level

  • Character frequency distributions
  • Case usage patterns
  • Vowel/consonant ratios
  • Special character usage

Swedish-Specific

  • Swedish character frequency (å, ä, ö)
  • Compound word detection
  • Function word patterns
  • Definite article usage

Stylometric

  • Yule's K (vocabulary richness)
  • Simpson's D (diversity index)
  • Shannon entropy
  • Burstiness metrics

Use Cases

  • Author Attribution: Identify the likely author of anonymous or disputed texts by comparing against known writing samples.
  • Plagiarism Detection: Detect potential plagiarism or ghostwriting by comparing stylistic consistency across texts.
  • Forensic Linguistics: Support legal investigations by analyzing writing style in disputed documents.
  • Academic Research: Study writing style evolution, authorship patterns, and linguistic variation.
  • Content Verification: Verify claimed authorship of historical or literary texts through style comparison.

Technical Details

Language Support: Swedish (optimized)
Total Features: 67+
Recommended Text Length: 400+ words
Dimensionality Reduction: PCA, t-SNE
Similarity Metrics: Cosine, Euclidean, Manhattan
